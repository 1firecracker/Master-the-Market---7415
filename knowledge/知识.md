# ALGOGENE 平台数据获取与处理知识库

## 1. getHistoricalBar API 使用经验

### 1.1 股票代码格式规则

**正确格式**：
- 港股：`00005HK`（5位数字+HK，无点号）
- 规则：港股代码需要补齐到5位数字（前面补0）
  - `0005.HK` → `00005HK`
  - `0939.HK` → `00939HK`
  - `0700.HK` → `00700HK`

**错误格式**：
- `0005.HK`（带点号，不支持）

### 1.2 函数调用方式

```python
from AlgoAPI.AlgoAPIUtil import getHistoricalBar

# 使用位置参数（不是关键字参数）
contract = {"instrument": "00005HK"}
count = 1000                    # 数据条数
interval = "D"                  # 时间间隔：D=日线, H=小时, M=分钟
timestamp = "2024-12-31"        # 截止时间

arr = getHistoricalBar(contract, count, interval, timestamp)
```

### 1.3 返回数据结构

**数据类型**：`collections.OrderedDict`（有序字典）

**结构**：
- **键**：时间戳字符串（如 `'2020-12-17 00:00:00'`）
- **值**：包含OHLCV数据的字典

**每个bar包含的字段**：
- `t`: 时间戳（字符串格式：'yyyy-mm-dd hh:mm:ss'）
- `o`: 开盘价（open）
- `h`: 最高价（high）
- `l`: 最低价（low）
- `c`: 收盘价（close）
- `b`: 收盘买价（bid）
- `a`: 收盘卖价（ask）
- `m`: 中间价（mid）
- `v`: 成交量（volume）
- `instrument`: 标的代码
- 其他字段：`expiry`, `right`, `strike`, `symbol`, `bb`, `ab`

### 1.4 数据转换最佳实践

```python
# 最优方法：直接提取值列表
if isinstance(arr, dict) and len(arr) > 0:
    rows = list(arr.values())  # 提取所有bar数据
    df = pd.DataFrame(rows)    # 每个值已经是完整字典
    df["t"] = pd.to_datetime(df["t"])  # 转换时间
    df = df.sort_values("t").reset_index(drop=True)
```

### 1.5 参数说明

- `count`: 请求的数据条数（实际返回可能更少）
- `interval`: 时间间隔
  - `'D'`: 日线
  - `'H'`: 小时线
  - `'M'`: 分钟线
- `timestamp`: 截止时间（返回该时间之前的数据）

### 1.6 注意事项

- 数据按时间升序排列（第一个键是最早的时间）
- 返回的数据条数可能少于请求的count（如果历史数据不足）
- `instrument` 必须在订阅列表中

## 2. 数据获取函数模板

### 2.1 股票日线数据获取

```python
def fetch_stock_daily(instrument: str, count: int = 1000, end_ts: str = "2024-12-31") -> pd.DataFrame:
    """获取股票日线数据"""
    contract = {"instrument": instrument}
    arr = getHistoricalBar(contract, count, "D", end_ts)
    
    if not arr:
        return pd.DataFrame()
    
    # 转换为DataFrame
    rows = list(arr.values())
    df = pd.DataFrame(rows)
    
    # 处理时间列
    if "t" in df.columns:
        df["t"] = pd.to_datetime(df["t"])
        df = df.sort_values("t").reset_index(drop=True)
    
    return df  # 列：t,o,h,l,c,v
```

## 3. 技术因子计算

### 3.1 移动平均线（MA）

```python
def ta_ma(series: pd.Series, window: int) -> pd.Series:
    """计算移动平均线"""
    return series.rolling(window).mean()
```

### 3.2 相对强弱指标（RSI）

```python
def ta_rsi(series: pd.Series, window: int = 14) -> pd.Series:
    """计算RSI指标"""
    delta = series.diff()
    gain = (delta.clip(lower=0)).rolling(window).mean()
    loss = (-delta.clip(upper=0)).rolling(window).mean()
    rs = gain / (loss.replace(0, np.nan))
    rsi = 100 - (100 / (1 + rs))
    return rsi
```

### 3.3 使用示例

```python
# 为每只股票计算技术因子
tech_factors = {}
for stock, df in stock_frames.items():
    if df.empty:
        continue
    tmp = df[["t", "c", "v"]].copy()
    tmp["MA5"] = ta_ma(tmp["c"], 5)
    tmp["MA20"] = ta_ma(tmp["c"], 20)
    tmp["RSI14"] = ta_rsi(tmp["c"], 14)
    tech_factors[stock] = tmp
```

### 4.8 简单情绪分析

```python
def simple_sentiment(text: str) -> int:
    """简单关键词情绪分析"""
    pos = ["涨", "利好", "增长", "盈利", "突破", "up", "gain", "beat"]
    neg = ["跌", "利空", "下降", "亏损", "危机", "down", "loss", "miss"]
    score = 0
    if not isinstance(text, str):
        return 0
    for w in pos:
        if w in text:
            score += 1
    for w in neg:
        if w in text:
            score -= 1
    return score

# 应用情绪分析
if "title" in news_df.columns:
    news_df["sentiment"] = news_df["title"].apply(simple_sentiment)
elif "content" in news_df.columns:
    news_df["sentiment"] = news_df["content"].apply(simple_sentiment)

# 按日期聚合
daily_news = news_df.groupby("date").agg(
    news_count=("sentiment", "size"),
    sentiment_sum=("sentiment", "sum")
).reset_index()
```

## 5. 经济统计数据

### 5.1 经济数据源概述

ALGOGENE 经济数据库收集了全球不同国家和地区的 10,000+ 经济时间序列数据。数据库包含 100,000+ 经济时间序列，为宏观经济分析和量化策略开发提供支持。

**注意**：为了运行效率，搜索结果最多列出 10,000 条匹配记录。建议进一步细化搜索条件以获取所需的时间序列。

### 5.2 实时经济数据回调

经济事件数据可以通过回调函数 `on_econsdatafeed` 访问。数据可以通过 JSON/字典键方法访问。以下示例展示如何打印接收到的数据流到控制台：

```python
def on_econsdatafeed(self, ed, ab):
    """经济数据回调函数"""
    self.evt.consoleLog(ed)  # 打印完整数据
    # 或访问具体字段
    print(f"时间序列ID: {ed['series_id']}")
    print(f"标题: {ed['title']}")
    print(f"发布时间: {ed['timestamp']}")
    print(f"数值: {ed['value']}")
    print(f"日期: {ed['date']}")
```

### 5.3 经济数据字段说明

经济数据对象 `ed` 包含以下字段：

| 字段名 | 数据类型 | 说明 | 示例 |
|--------|---------|------|------|
| `timestamp` | datetime | 经济数据发布时间戳（时区标准化为 GMT+0） | `2020-02-03 07:01:02.060000` |
| `series_id` | string | 经济时间序列的唯一标识符 | `RECPROUSM156N` |
| `title` | string | 经济时间序列的描述 | `"Smoothed U.S. Recession Probabilities"` |
| `tag` | list | 时间序列的高级分类标签 | `['recession indicators', 'academic data']` |
| `seasonal_adj` | string | 标识时间序列是否经过季节性调整 | `"SA"`（季节性调整）或 `"NSA"`/空白（未调整） |
| `popularity` | int | 指定该时间序列在行业专业人士中的使用广泛程度 | 0-100（值越高，使用越广泛） |
| `obs_start` | date | 时间序列的最早可用日期 | `1967-06-01` |
| `src` | string | 经济时间序列的来源提供者或发布者 | `"chauvet, marcelle"` |
| `geo` | string | 该经济时间序列测量或适用的国家或地区 | `"usa"` |
| `freq` | string | 时间序列的报告频率 | `"monthly"`（月度） |
| `date` | date | 时间序列测量期间的结束日期 | `2019-12-01` |
| `units` | string | 报告观测值的单位 | `"Percent"`（百分比） |
| `value` | float | 报告的数值 | `2.06` |

- `CPIAUCSL`: 美国CPI（消费者价格指数）
- `A193RC1A027NBEA`: GDP增长

### 5.6 数据探索建议

由于数据库包含 100,000+ 经济时间序列，建议：
1. **细化搜索条件**：使用 `tag`、`geo`、`freq` 等字段过滤
2. **关注流行度**：`popularity` 值高的时间序列通常更受关注
3. **检查数据可用性**：查看 `obs_start` 确保有足够的历史数据
4. **季节性调整**：根据分析需求选择 `seasonal_adj` 为 `"SA"` 或 `"NSA"` 的数据

        ret_panel = pd.concat(ret_df, axis=1).dropna()
