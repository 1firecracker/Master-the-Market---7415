## 一、文档完整翻译（带要点）

### 项目背景

在本项目中，你将利用 **ALGOGENE 平台** 开发一个**算法交易策略**。
目标是创建、测试并优化一个有潜力在真实市场中执行的交易算法。

假设你是一家**对冲基金的量化研究员**，需要为潜在投资者开发新的交易策略。
你将获得 **2020–2024 年的五年期 1 分钟级数据**，包括市场数据、新闻、经济指标等。
你可以自由设计交易策略，包括数学模型、输入数据集、交易标的等。

若你的策略依赖外部数据或自定义模型，可参考以下教程将其导入 ALGOGENE 系统进行回测：

* 导入自定义数据集指南：[https://algogene.com/community/post/26](https://algogene.com/community/post/26)

## 二、作业重点分析与策略建议

根据评分项分布与项目目标，本作业重点在于**完整设计一个可落地的交易系统**，并证明其**可行性与稳定性**。以下是权重最高、最值得深入的部分：

| 模块              |     建议重点投入方向 |
| --------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Implementation Details (20%)**        | ✅ 详细描述交易逻辑、信号生成、模型结构（如回归、LSTM、随机森林、技术指标等）<br>→ 建议实现可运行代码，展示关键函数逻辑                                          |
| **Risk Management (20%)**               | ✅ 明确风险来源（波动、杠杆、滑点、流动性等）并提出量化控制手段（止损、VaR、max drawdown）                                                      |
| **Backtest Performance (20%)**          | ✅ 回测部分要求图表与指标分析（Sharpe Ratio, Max DD, CAGR, Sortino）<br>→ 建议使用 ALGOGENE 平台 + Python Pandas 可视化分析           |
| **Capital Management (15%)**            | ⚙️ 分析资金分配、杠杆效应、交易规模变化的影响<br>→ 可提出自适应仓位策略或Kelly Criterion思路                                                 |
| **Executive Summary (15%)**             | ✍️ 清晰说明交易理念与市场逻辑（如动量策略、均值回归、新闻驱动等）                                                                        |
| **Expectations for Real Trading (10%)** | 💡 分析策略在真实市场的表现差异与限制（延迟、手续费、流动性）                                                                           |
