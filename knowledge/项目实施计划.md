    # 简单的情绪评分（可后续用LLM或NLP模型改进）

    for word in positive_keywords:
        if word in news_text:

        if word in news_text:
            score -= 1

#### 1.5 策略假设与模型设计

**多因子模型设计：**

```python
# 模型框架
# 预测目标：未来N天收益率（如未来5天收益率）
# 输入：多个因子值
# 方法：线性回归 / 机器学习模型

# 方法1：线性多因子模型
# R(t+1) = α + β1*F1(t) + β2*F2(t) + ... + βn*Fn(t) + ε

# 方法2：机器学习模型
# R(t+1) = ML_Model(F1(t), F2(t), ..., Fn(t))

# 交易信号生成：
# - 如果预测收益率 > 阈值 → 买入
# - 如果预测收益率 < -阈值 → 卖出
# - 否则 → 持有/空仓
```

**策略假设：**

1. **市场假设**
   - 股票价格受多个因子共同影响
   - 因子与收益的关系在样本期内相对稳定
   - 新闻和经济指标对股价有可预测的影响

2. **模型假设**
   - 因子与收益存在线性或非线性关系
   - 因子可以量化并标准化
   - 模型可以捕捉因子与收益的关系

3. **适用市场**
   - 主要适用于港股市场
   - 适用于流动性较好的大盘股
   - 适用于有足够新闻和经济数据覆盖的股票

class AlgoEvent:

        self.orderPairCnt = 0

        # 模型参数
        self.model = None  # 机器学习模型
        self.factor_names = [
            'price_momentum', 'price_volatility', 'rsi', 
            'news_sentiment', 'news_count',

            'take_profit': 0.05,
            'max_drawdown': 0.15
        }
        
    def calculate_factors(self, bd, news_data, econ_data):
        """计算所有因子"""
        factors = {}
        
        # 1. 价格因子
        if len(self.price_history) >= 20:
            returns = np.diff(self.price_history[-20:]) / self.price_history[-20:-1]
            factors['price_momentum'] = np.mean(returns[-5:])  # 5日动量
            factors['price_volatility'] = np.std(returns)      # 波动率
            factors['rsi'] = self.calculate_rsi(self.price_history[-14:])
        
        # 2. 新闻因子
        factors['news_sentiment'] = self.calculate_news_sentiment(news_data)

        # 3. 经济因子
        factors['gdp_growth'] = self.get_econ_factor(econ_data, 'GDP')
        factors['cpi_change'] = self.get_econ_factor(econ_data, 'CPI')
        
        return factors
    
    def predict_return(self, factors):
        """使用模型预测未来收益率"""
        if self.model is None:

        # 将因子转换为模型输入格式

        predicted_return = self.model.predict([factor_vector])[0]

## 多因子模型实施要点

### 因子选择建议

**必须包含的因子类型：**
1. **价格因子**（3-5个）：动量、波动率、技术指标
2. **新闻因子**（2-3个）：情绪、数量、类别
3. **经济因子**（2-3个）：GDP、CPI、利率等

**因子数量：** 建议10-20个因子，避免过多导致过拟合

### 模型选择建议

**推荐方法（按复杂度）：**
1. **线性回归**：简单、可解释性强
2. **随机森林**：捕捉非线性关系，特征重要性
3. **XGBoost**：更强的预测能力，但可能过拟合

### 数据对齐

**关键挑战：**
- 价格数据：1分钟级
- 新闻数据：可能不规律
- 经济指标：通常是日度/周度/月度

**解决方案：**
- 统一到日度频率
- 使用前向填充处理缺失值
- 确保因子计算无未来信息泄露
