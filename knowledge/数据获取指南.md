## Jupyter Notebook 简介

### 什么是 Jupyter Notebook？

Jupyter Notebook 是一个交互式开发环境，允许你创建和共享包含以下内容的文档：
- 实时代码
- 数学公式
- 文本说明
- 图表和可视化
- 链接等

### 主要用途

在 ALGOGENE 平台上，Jupyter Notebook 可用于：

- ✅ **回测前分析**（Pre-backtest analysis）
- ✅ **数据转换**（Data transformation）
- ✅ **数值模拟**（Numerical simulation）
- ✅ **统计建模**（Statistical modeling）
- ✅ **数据可视化**（Data visualization）
- ✅ **机器学习**（Machine learning）

### Jupyter Dashboard

Jupyter Dashboard 是控制面板，功能类似文件管理器：
- 显示本地文件
- 打开 Notebook 文档
- 关闭 Kernel
- 文档管理

### Notebook Kernel

- **作用**：执行 Notebook 中的代码
- **资源分配**：ALGOGENE 自动分配计算资源
- **限制**：如果 CPU/RAM 使用超过限制，Kernel 可能被关闭

## 数据获取方法

### 1. 市场数据（Market Data）

#### 方法 A：使用 AlgoAPI 工具函数（推荐）

```python
from AlgoAPI.AlgoAPIUtil import getHistoricalBar

contract = {"instrument": "EURUSD"}
count = 50                    # 获取数据条数
interval = "D"               # 时间间隔：D=日线, H=小时, M=分钟
timestamp = "2019-11-30"     # 截止时间

arr = getHistoricalBar(contract, count, interval, timestamp)

# 数据格式
for k in arr:
    print(arr[k])
    # 输出包含：'t'（时间）, 'o'（开盘）, 'h'（最高）, 'l'（最低）, 
    #          'c'（收盘）, 'v'（成交量）等字段
```

#### 方法 B：使用 REST API

```python
import requests, json

USER = "your_username"
API_KEY = "your_api_key"  # 从 [Settings] > [User Profile] 获取

def getprice(symbol, count, interval, timestamp):
    url = 'https://algogene.com/rest/v1/history_price'
    headers = {'Content-Type': 'application/json'}
    params = {
        "instrument": symbol,
        'user': USER,
        'api_key': API_KEY,
        'count': count,
        'interval': interval,
        'timestamp': timestamp
    }
    res = requests.get(url, params=params, headers=headers)
    return res.json()

data = getprice("EURUSD", 100, "D", '2020-12-31')
```

**API Key 获取位置：**
- `[Settings]` > `[User Profile]`

### 示例 3：多标的对比

```python
%matplotlib inline
import numpy as np
from matplotlib import pyplot as plt
from AlgoAPI.AlgoAPIUtil import getHistoricalBar

def getdata(contract, count, interval, timestamp):
    arr = getHistoricalBar(contract, count, interval, timestamp)
    return arr

# 获取两个标的的数据
data1 = getdata(
    contract={"instrument": "EURCHF"},
    count=50,
    interval="D",
    timestamp="2019-11-30"
)

data2 = getdata(
    contract={"instrument": "EURUSD"},
    count=50,
    interval="D",
    timestamp="2019-11-30"
)

# 提取收盘价
arr_time = [data1[k]['t'] for k in data1]
arr_close1 = [data1[k]['c'] for k in data1]
arr_close2 = [data2[k]['c'] for k in data2]

# 绘制对比图
x = np.array(arr_time)
y1 = np.array(arr_close1)
y2 = np.array(arr_close2)

plt.plot(x, y1, '-', label="EURCHF")
plt.plot(x, y2, '-', label="EURUSD")
plt.style.use(['dark_background'])
plt.title("Closing Price Comparison")
plt.legend()
plt.show()
```

## 注意事项

### 1. API Key 获取

- **位置**：`[Settings]` > `[User Profile]`
- **用途**：使用 REST API 时需要
- **安全**：不要将 API Key 提交到公开代码库

### 2. 数据格式说明

#### 市场数据（getHistoricalBar）

返回字典，键为索引，值为包含以下字段的字典：
- `'t'`：时间戳（timestamp）
- `'o'`：开盘价（open）
- `'h'`：最高价（high）
- `'l'`：最低价（low）
- `'c'`：收盘价（close）
- `'v'`：成交量（volume）

#### 新闻数据（getHistoricalNews）

返回字典列表，每个字典包含新闻的详细信息。

#### 经济指标（getHistoricalEconstat）

返回字典列表，每个字典包含：
- `'date'`：日期
- `'value'`：指标值

#### 链上数据（getChain_*）

返回字典列表，每个字典包含：
- `'t'`：时间戳
- `'v'`：数值

### 3. 时间间隔参数

`interval` 参数可选值：
- `"D"`：日线数据
- `"H"`：小时数据
- `"M"`：分钟数据

### 4. 可视化设置

使用 matplotlib 时，建议添加：
```python
%matplotlib inline
plt.style.use('dark_background')  # 深色背景主题
```

### 5. 资源限制

- Kernel 可能因 CPU/RAM 使用超限被关闭
- 大数据量查询时注意分批处理
- 长时间运行的任务可能被中断

### 6. 文件管理

- 所有 Notebook 保存在 `/notebook` 目录
- 可以通过 `[My History]` > `[File Viewer]` 管理文件
- 支持上传本地 Notebook 文件

## 数据获取方法总结

| 数据类型 | 函数/API | 用途 |
|---------|---------|------|
| **市场数据** | `getHistoricalBar()` | 获取历史价格数据（OHLCV） |
| **新闻数据** | `getHistoricalNews()` | 获取历史新闻 |
| **实时新闻** | REST API `/realtime_news` | 获取实时新闻 |
| **经济指标** | `getHistoricalEconstat()` | 获取经济统计数据 |
| **链上数据** | `getChain_*()` 系列 | 获取区块链相关数据 |
